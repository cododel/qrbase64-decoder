# 🔤 Методы Декодирования QR Контента

## Обзор

QR сканер поддерживает **9 различных методов декодирования** с автоматическим определением типа кодирования и возможностью ручного выбора.

## 🚀 Доступные Методы

### 1. 🔤 Base64 (По умолчанию)
- **Описание**: Декодирование Base64 строк
- **Использование**: Стандартное кодирование для бинарных данных в текстовом формате
- **Пример**: `SGVsbG8gV29ybGQ=` → `Hello World`
- **Автоопределение**: ✅ Автоматически определяется

### 2. 🌐 URL Decode
- **Описание**: Декодирование URL-кодированных строк
- **Использование**: Для URL параметров и веб-ссылок
- **Пример**: `Hello%20World%21` → `Hello World!`
- **Автоопределение**: ✅ Автоматически определяется

### 3. 🔢 Hex
- **Описание**: Декодирование шестнадцатеричных строк
- **Использование**: Для бинарных данных в hex формате
- **Пример**: `48656c6c6f20576f726c64` → `Hello World`
- **Автоопределение**: ✅ Автоматически определяется

### 4. 🔄 ROT13
- **Описание**: Декодирование ROT13 шифра
- **Использование**: Простое буквенное шифрование (сдвиг на 13)
- **Пример**: `Uryyb Jbeyq` → `Hello World`
- **Автоопределение**: ❌ Требует ручного выбора

### 5. 🏛️ Caesar Cipher
- **Описание**: Декодирование шифра Цезаря (сдвиг на 3)
- **Использование**: Классическое шифрование сдвигом
- **Пример**: `Khoor Zruog` → `Hello World`
- **Автоопределение**: ❌ Требует ручного выбора

### 6. ↩️ Reverse
- **Описание**: Обращение строки задом наперед
- **Использование**: Простое обращение символов
- **Пример**: `dlroW olleH` → `Hello World`
- **Автоопределение**: ❌ Требует ручного выбора

### 7. 🔐 Password Protected
- **Описание**: Простое XOR шифрование с паролем
- **Использование**: Защищенные паролем данные
- **Пример**: С паролем `secret` декодирует зашифрованные данные
- **Автоопределение**: ❌ Требует ручного выбора + пароль
- **Особенности**: Требует ввода пароля

### 8. 📋 JSON
- **Описание**: Форматирование JSON с отступами
- **Использование**: Красивое отображение JSON данных
- **Пример**: `{"name":"test"}` → форматированный JSON
- **Автоопределение**: ✅ Автоматически определяется

### 9. 📝 Без декодирования
- **Описание**: Показать оригинальный текст как есть
- **Использование**: Когда декодирование не требуется
- **Пример**: `Hello World` → `Hello World`
- **Автоопределение**: ❌ По запросу пользователя

## 🎯 Автоматическое Определение

При сканировании QR кода система автоматически пытается определить тип кодирования:

```typescript
export function detectEncodingType(text: string): DecodingMethod {
  // 1. Проверка Base64
  if (/^[A-Za-z0-9+/]*={0,2}$/.test(text) && text.length % 4 === 0) {
    return "base64";
  }
  
  // 2. Проверка URL encoding
  if (text.includes('%') && /^[A-Za-z0-9%._~:/?#[\]@!$&'()*+,;=-]*$/.test(text)) {
    return "url";
  }
  
  // 3. Проверка Hex
  if (/^[0-9A-Fa-f\s]*$/.test(text) && text.replace(/\s/g, '').length % 2 === 0) {
    return "hex";
  }
  
  // 4. Проверка JSON
  if ((text.startsWith('{') && text.endsWith('}')) || 
      (text.startsWith('[') && text.endsWith(']'))) {
    return "json";
  }
  
  // По умолчанию Base64
  return "base64";
}
```

### Автоматический Режим

### Ручной Выбор
1. Отсканируйте QR код
2. Выберите нужный метод из выпадающего списка
3. При необходимости введите пароль (для Password Protected)
4. Результат обновится автоматически

## 🛡️ Безопасность

### Password Protected Метод
- Использует простое **XOR шифрование**
- Пароль **не сохраняется** нигде
- Пароль **удаляется** при сбросе камеры
- **Локальная обработка** - пароль не покидает браузер

```typescript
function decodePasswordProtected(text: string, password: string): DecodingResult {
  let decoded = '';
  for (let i = 0; i < text.length; i++) {
    const textChar = text.charCodeAt(i);
    const keyChar = password.charCodeAt(i % password.length);
    decoded += String.fromCharCode(textChar ^ keyChar);
  }
  return { success: true, decodedText: decoded, originalText: text, method: "password-protected" };
}
```
